Windows

Windows 10, 11 · 64-bit

Windows के लिए डाउनलोड

Invoiceo-Setup-Windows.exe

  1. डाउनलोड हुई फ़ाइल खोलें।
  2. अगर “Windows protected your PC” दिखे, तो More info दबाएं, फिर Run anyway दबाएं। यह संदेश इसलिए आता है क्योंकि इंस्टॉलर पर अभी code-sign नहीं हुआ है।
  3. Setup पूरा करें। फिर Start मेन्यू में Invoiceo मिल जाएगा।

macOS

macOS 12 Monterey या उसके बाद का

macOS के लिए डाउनलोड

Invoiceo-macOS.dmg

  1. .dmg फ़ाइल खोलें और Invoiceo को Applications में खींचकर छोड़ दें।
  2. Invoiceo खोलें। अगर macOS कहे कि वह ऐप की जांच नहीं कर सकता, तो Done दबाएं (Move to Bin नहीं)। ऐप पर अभी Apple की notarisation नहीं हुई है, इसलिए ऐसा होता है।
  3. System Settings → Privacy & Security खोलें, नीचे Invoiceo वाले संदेश में Open Anyway दबाकर पक्का करें। (macOS 14 या पुराने में, Applications में Invoiceo पर Control-click करके Open चुन सकते हैं।)
  4. इसके बाद ऐप सामान्य रूप से खुलेगा।
आपके कंप्यूटर के लिए

Linux

Ubuntu 22.04+, Debian 12+, Mint 21+ और अन्य

.deb डाउनलोडAppImage डाउनलोड

Invoiceo-Linux.deb
Invoiceo-Linux.AppImage
